# BTCS303P - Lab 3 and Lab 4 (React)

| Lab | Folder | Topic |
|---|---|---|
| 3 | lab3-todo-react | React Todo app: components, useState/useEffect, props |
| 4 | lab4-react-router-shop | SPA: react-router-dom, Context API cart/favorites, loading, 404 |

Each folder has its own README and `component-tree.svg` (component tree diagram).

## Run (needs Node.js from nodejs.org)
```
cd lab3-todo-react        (or lab4-react-router-shop)
npm install
npm run dev
```
